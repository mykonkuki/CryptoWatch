# CryptoWatch
5개 거래소 통합 암호화폐 시세 대시보드
5개 거래소의 암호화폐 시세를 한눈에 확인할 수 있는 통합 대시보드입니다.

거래소별 가격과 변동률을 비교하고, 주요 암호화폐의 시장 흐름을 빠르게 파악할 수 있도록 구성했습니다.

## 주요 기능

- 5개 거래소의 암호화폐 시세 통합 조회
- 거래소별 가격 비교
- 암호화폐별 현재가 및 등락률 확인
- 상승·하락 종목 구분
- 실시간 또는 주기적 시세 업데이트
- 반응형 웹 디자인
- 데스크톱 및 모바일 환경 지원
- 직관적인 대시보드 형태의 데이터 시각화

## 화면 구성

### 대시보드

전체 암호화폐 시장의 주요 시세와 거래소별 가격을 확인할 수 있습니다.

### 거래소별 시세

거래소를 기준으로 암호화폐 가격, 변동률, 업데이트 시간을 비교할 수 있습니다.

### 암호화폐별 비교

특정 암호화폐를 선택해 거래소별 가격 차이를 확인할 수 있습니다.
